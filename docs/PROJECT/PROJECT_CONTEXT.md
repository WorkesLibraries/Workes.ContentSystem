# PROJECT CONTEXT

## Purpose

Orient contributors and AI assistants before project work.

## Project Summary

Workes.ContentSystem is planned as an engine-neutral content-entry backend.

It should support simple in-memory streams first, then grow toward richer structures and optional attachments. The package should be useful as a foundation for a future ConsoleSystem rebuild, but it should not become console-specific.
